Oaken:Build — Agente de IA pra Gestão de Obra

App full-stack para mestre de obra e pequena empreiteira: chat com IA que calcula materiais via function-calling, cronograma por caminho crítico, orçamento e fotos da obra.

Groq Function Calling Express + Prisma Gemini Vision JWT + bcrypt Agent
Nota: a demo abaixo corre num plano gratuito do Render — pode "adormecer" após uns minutos sem uso (o primeiro pedido demora a acordar) e o armazenamento não é permanente. Cria uma conta e testa à vontade; para uso real, o repositório tem o guia de deploy em VPS com persistência de verdade.

// Registry de ferramentas expostas ao agente via function-calling
const toolDefinitions = [{
  type: 'function',
  function: {
    name: 'calcular_ferro',
    description: 'Calcula kg de vergalhao para um volume de concreto',
    parameters: { type: 'object', properties: {
      volume_concreto: { type: 'number' },
      elemento: { type: 'string', enum: ['laje','viga','pilar','fundacao'] },
    }, required: ['volume_concreto'] },
  },
}];

// Middleware: nunca confia em projectId do body sem checar dono
async function ensureProjectAccess(req, res, next) {
  const project = await prisma.project.findUnique({
    where: { id: req.params.projectId },
    select: { id: true, userId: true },
  });
  if (!project || project.userId !== req.user.id)
    return res.status(403).json({ error: 'Sem acesso.' });
  next();
}

O que aprendi

  • Visão aplicada a canteiro de obra — o utilizador tira foto pelo telemóvel e um modelo de visão descreve a etapa, aponta risco de segurança visível ou problema de execução. Como o Groq não tem modelo de visão no tier gratuito, a análise usa um provedor separado (Gemini), configurável por variável de ambiente sem tocar no código.
  • Moeda multi-região — Kwanza, Real e Euro com conversão real; os valores ficam sempre guardados em Kwanza na base, e só a apresentação muda.
  • Function-calling com contexto de negócio — O agente decide qual ferramenta chamar (cálculo de material, caminho crítico, matriz de risco) a partir da linguagem natural do mestre de obra.
  • Upload validado de verdade — Checagem de assinatura binária real (magic bytes) do ficheiro, não só da extensão declarada pelo cliente.
  • Async error handling em Express 4 — Revisão própria encontrou que handlers assíncronos sem wrapper podiam derrubar o processo inteiro num erro de banco; corrigido com um asyncHandler aplicado a todas as rotas.
  • Caminho crítico (CPM) — Ordenação topológica + deteção de ciclo antes de calcular folga e caminho crítico entre tarefas dependentes.
