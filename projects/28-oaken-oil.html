Código destaque

// Sorteio de 30 questoes do pool do modulo, com opcoes embaralhadas
// a cada tentativa - impede memorizar respostas erradas em retries
function draftExam(moduleId) {
  const pool = MODULE_QUESTIONS[moduleId];
  const picked = shuffle([...pool]).slice(0, 30);
  return picked.map(q => ({
    ...q,
    options: shuffleWithAnswer(q.options, q.answer),
  }));
}

// Gate sequencial: so desbloqueia o modulo seguinte apos 70%+
function submitExam(moduleId, answers) {
  const correct = grade(answers);
  const pct = (correct / 30) * 100;
  const approved = pct >= 70;

  saveModuleState(moduleId, { approved, pct });
  if (approved && moduleId < 17) unlockModule(moduleId + 1);
  if (approved && moduleId === 17) redirectToCertificate();
}

O que aprendi

  • Gate sequencial sem backend — Todo o estado de progresso (módulo aprovado, tentativa em curso, tempo restante) persiste em localStorage, sem precisar de servidor.
  • Banco de questões estruturado — 655 questões extraídas e validadas por módulo (mínimo 4 opções, resposta 0-3, sem duplicados), mapeadas pelos comentários originais do conteúdo-fonte.
  • Anti-memorização — Sorteio de 30 questões + opções embaralhadas a cada tentativa, em vez de variantes fixas pré-geradas.
  • Certificado verificável — QR code que aponta para uma página de verificação pública com o código do certificado.
